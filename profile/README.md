I’m Jozz. With JozzDart, I want to create tools that feel simple, thoughtful, and genuinely pleasant to use.

I care deeply about the experience behind every package: how easily someone can get started, how naturally the API reads, how clearly things are documented, and how reliably everything behaves. My goal is to take care of the complicated details so others don’t have to.

### What matters to me

1. **Less friction** - Minimal setup, less repetition, and as little boilerplate as possible.
2. **Clarity** - APIs that feel natural, familiar, and easy to understand.
3. **Reliability** - Careful testing, predictable behavior, and attention to edge cases.
4. **Practicality** - Solving real problems in ways that are genuinely useful.
5. **Thoughtful growth** - Keeping things approachable for small projects while leaving room for bigger ones.


### Production-ready Packages

- **[time_plus](https://github.com/jozzdart/time_plus)** - Practical extensions for working with dates and durations.
- **[exui](https://github.com/jozzdart/exui)** - Extensions for building Flutter interfaces with less boilerplate.
- **[terminice](https://github.com/jozzdart/terminice)** - Components and styling for polished terminal interfaces.
- **[hivez](https://github.com/jozzdart/hivez)** - A production-focused layer for working with Hive databases.
- **[track](https://github.com/jozzdart/track)** - Persistent streaks, counters, histories, and records.
- **[limit](https://github.com/jozzdart/limit)** - Persistent cooldowns and rate limits.
- **[shrink](https://github.com/jozzdart/shrink)** - One-line, lossless data compression.
- **[jozz_events](https://github.com/jozzdart/jozz_events)** - A typed, framework-agnostic event system.
- **[prf](https://github.com/jozzdart/prf)** - Simple, type-safe local preferences.
